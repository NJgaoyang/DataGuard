# Agent 生命周期（V7）

运行状态只有两种：**启用** 与 **已停用**。到期时间和 Token 是否需要重签属于凭据属性，不构成额外运行状态。

| 状态 | 允许编辑授权 | 允许启停 | 允许删除 | 查询 |
|---|---|---|---|---|
| 启用 | 否 | 停用 | 否 | 仅在凭据未到期、授权有效时可查询 |
| 已停用 | 是 | 启用 | 是 | 拒绝 |

- 新建 Agent 默认启用，Token 仅展示一次；停用立即使 Token 无法访问，重新启用且凭据有效时可以继续使用原 Token。
- Token 轮换属于独立的安全操作，可在启用或已停用状态执行，生成新的 Token 和有效期并立即使旧 Token 失效；旧 Token 不记录明文。
- 升级前的「已撤销」迁移为「已停用」，其原 Token 哈希会被永久覆盖。第一次重新启用时自动重签 Token，前端必须展示一次；旧 Token 永不恢复。过期 Token 启用时也按此方式重签。
- 已启用状态不允许任何授权修改（批量修改、添加或移除表/字段），所有写操作均由后端事务与行锁校验状态，不只依赖按钮置灰。
- 删除是**软删除**：要求停用，设置 `deleted_at`、废弃凭据、撤销表/字段授权、禁用针对该 Agent 的规则、拒绝未决请求，管理列表不再显示此记录。
- `dg_requests` 和 `dg_audit` 历史不删除，Agent 身份主键仍可关联历史记录。已删除 Agent 不能再次启用或轮换 Token。
- MCP/REST 读请求强制校验 `enabled=1`、`deleted_at IS NULL`、`token_reset_required=0`（凭据哈希校验）和凭据有效期。
- V7 为现有数据新增 `deleted_at` 与 `token_reset_required`，历史 `revoked_at` 仅暂存以保障有数据迁移时前一版可安全回滚，不再参与应用状态判断。不会为了升级而删除现有审批或审计数据。
