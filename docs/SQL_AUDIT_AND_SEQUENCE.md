# 访问记录：脱敏 SQL 模板与列表序号

## 新增 SQL 审计

Flyway V8 为 `dg_requests` 增加 `sql_template TEXT NULL`。存的是解析、授权后用于执行的只读 SQL **脱敏模板**，不是带敏感值的原始 SQL。

- SQL 字符串字面量、数字字面量都会脱敏，`?` 占位符保留结构；**绑定参数值绝不落库**。
- 真实数据库执行仍使用原 SQL + PreparedStatement 参数，不受显示模板影响。
- 查询命中多个授权表并生成多个请求记录时，每个请求记录引用同一脱敏模板；待审批、被规则拒绝、成功或执行失败的请求同样可追溯。
- `GET /api/requests/page`、`GET /api/requests/{id}` 和后台审批记录会读取 `sqlTemplate`，遵循原接口的用户/审批人/管理员权限。
- 访问记录列表增加“SQL 摘要”（单行省略显示）；访问记录详情展示“查询 SQL（已脱敏）”；新增 SQL 字段可通过现有搜索框查找（仅匹配脱敏模板）。
- 旧历史记录没有存过 SQL，升级后不会猜测或伪造内容，显示“历史记录未保存 SQL”。
- SQL 在通过 AST 校验和授权之前被拒绝的请求不会生成正常查询/审批记录；可在安全审计中看到拒绝事件，但不能反推出原始 SQL。
- 这些日志仍暴露数据表和字段名称，因此应按访问记录现有权限保护，避免向未授权用户开放。

## 序号

“数据源”“Agent 管理”“访问规则”主列表按当前筛选结果全局顺序编号，翻页后继续递增，而非每页重新从 1 开始。
“工作台 → 最近访问”和“Agent 详情 → 使用情况 → 最近访问”无分页，序号从 1 开始。
“访问记录”原有服务端分页序号规则保持不变。
