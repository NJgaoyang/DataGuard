# 访问记录筛选（2026-10）

- 进入页面后默认查询用户浏览器所在时区的当天，起止日期都是当天；日期范围按后端 [from, to+1 day) 处理。
- 状态、Agent、数据源、SQL/表名搜索和日期为草稿过滤条件。只有点击查询才会应用新条件并请求第一页，修改控件本身不触发查询。
- 重置恢复“全部状态 / 全部 Agent / 全部数据源 / 搜索为空 / 日期当天”，不立即发起任何请求；只有点查询才应用重置后的条件。
- 翻页仍沿用最近一次已点击“查询”的条件，未提交的草稿不会意外影响分页。
- Agent / 数据源下拉列表从 GET /api/requests/filters 获得，此列表独立于当前分页和所有筛选条件，选择某数据源后仍可直接切换另一个。
- 后端候选项按当前登录用户的访问记录权限限定：管理员全部，其他账号仅本人申请或被指定审批的记录，不能通过筛选接口枚举无权限 Agent/数据源。
- 多次快速点击查询时使用序号忽略过期 HTTP 响应，不会由旧结果覆盖新结果。
